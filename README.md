# Sus: Little Wonder Lab Shorts Factory 📱

**Automatic 9:16 YouTube Shorts generator, designed to run entirely through GitHub on a phone.**

- **Output:** 720 × 1280 vertical MP4, H.264 + AAC, original drawings and music
- **Content:** preschool colors, shapes, and counting with original cartoon animals, robotic offline narration
- **Controls:** manual trigger or automatically on Tuesday and Friday
- **Price:** no paid APIs, runs with Python, FFmpeg, Pillow, and eSpeak NG on GitHub Actions
- **Default publishing:** no YouTube upload without OAuth secrets; if connected, uploads **PRIVATE** and **Made for Kids**

## Make a Short on your phone

1. Go to [Actions → Generate original cartoon](https://github.com/aurexvelion/Sus/actions/workflows/generate.yml).
2. Select **Run workflow**. On a small screen, use your phone browser's *Desktop site* toggle if necessary.
3. Pick **random**, **colors**, **counting**, or **shapes**.
4. Open the completed run, find **Artifacts**, and download the ZIP.
5. Inside are `episode.mp4`, `thumbnail.jpg`, `metadata.json`, and `captions.txt`. You can upload `episode.mp4` in the YouTube app.

All new runs create **portrait Shorts**, not horizontal videos. Older artifacts from before October 13, 2026 are still landscape.

## How it works

The scene planner chooses an authored story framework and shuffles visual objects to create a new episode. Python draws a complete 9:16 cartoon, eSpeak narrates it, a procedural pentatonic soundtrack plays underneath, and FFmpeg encodes the finished Short. The scripts are **not generated by an AI language model** and the animation is template-based, so avoid publishing large numbers of near-duplicates.

Locally:

```bash
# Install ffmpeg + espeak-ng using your operating system's package manager.
python -m pip install -r requirements.txt
python factory.py --topic random --format shorts --output build
python -m unittest discover -s tests -v
```

Optional previous layout: `python factory.py --format landscape --topic colors --output build`.

## Optional automatic private YouTube uploads

These are not activated yet. You need a Google Cloud project with **YouTube Data API v3**, OAuth consent, and the OAuth `youtube.upload` permission. Add these three GitHub Actions repository secrets (never commit or share them in chat):

- `YT_CLIENT_ID`
- `YT_CLIENT_SECRET`
- `YT_REFRESH_TOKEN`

When all three are present, the workflow attempts to upload each Short as **PRIVATE** and **Made for Kids**. Review the Short in YouTube Studio before manually publishing it. Shorts custom thumbnail upload availability depends on channel eligibility and may fail without blocking the actual video upload. A generated portrait thumbnail is always included in the ZIP.

## Safety and monetization

- YouTube recognizes square or vertical videos lasting up to three minutes as Shorts.
- Mark video content directed at preschool children **Made for Kids**.
- YouTube may reject repetitive, mass-produced videos from its Partner Program even if production is technically automated.
- YouTube monetization isn't guaranteed. The channel has to meet eligibility thresholds and content policies.
- Check every result for coherent speech, image clipping, educational accuracy, originality and age-appropriate material before publishing.
- GitHub Actions public repository usage is subject to GitHub's usage and retention limits.
